# ARTUR-TV 2.75 — исправления стабильности

В этой сборке внесены точечные изменения без переделки интерфейса:

1. Исправлена передача JVM-параметров в `gradlew`; скрипту также выставлен исполняемый атрибут.
2. Повторное подключение плеера привязано к поколению текущего воспроизведения и ключу канала. Отложенный повтор не должен запускать уже не выбранный канал; отложенная задача отменяется при смене потока и при закрытии экрана.
3. Счётчик повторных попыток теперь сбрасывается при выборе нового потока, а не при каждом кратком переходе в READY.
4. Обработка `catchup="none"` / `off` / `false` / `0` исправлена: отключённый архив не считается доступным и может переопределять глобальную настройку плейлиста.
5. Обработка Catch-up URL улучшена: шаблон `catchup-source` имеет приоритет, поддерживаются типовые варианты `?` / `&`, `utc`, `lutc`, `start`, `duration`, `offset`; добавлен более корректный резервный URL для Flussonic.
6. Сохранение плейлиста больше не удаляет предыдущий файл до подтверждения успешной замены; предусмотрен резервный файл и откат.
7. User-Agent синхронизирован с версией приложения 2.75.

## Проверка

- `M3uParser.kt` и `PlayerUtils.kt` успешно прошли отдельную проверку компиляции Kotlin с заглушками внешних Android/Media3/OkHttp API.
- Выполнены базовые проверки M3U и построения URL архива.
- Полная сборка APK в этой среде не выполнена: Gradle 8.6 отсутствовал в кэше, а среда не смогла подключиться к `services.gradle.org` для его загрузки. Поэтому APK не заявляется как проверенный.

- На обычных телефонах приложение стартует в вертикальной ориентации.

Проверки: AndroidManifest успешно разобран как XML; `gradlew` прошёл `sh -n`; Kotlin-файлы проверены на синтаксические ошибки компилятором Kotlin (полная компиляция невозможна без Android/Compose/Media3 зависимостей). ## Дополнительные исправления после проверки 2.76

1. В полноэкранном списке каналов выбор строки теперь сразу переключает канал и закрывает только боковую панель; полноэкранный режим остаётся включённым. Та же логика используется при подтверждении кнопкой OK на пульте.
2. В обычном интерфейсе активная категория теперь выделяется контрастной голубой заливкой, белой галочкой и более жирным текстом. Добавлен заголовок категории.
3. Добавлена диагностика аудиодорожек в Android Logcat под тегом `ARTUR_TV_AUDIO`: MIME/кодек, язык, число каналов, частота дискретизации, поддержка дорожки устройством и факт её выбора. Это помогает определить, почему на конкретном канале нет звука. Само отсутствие звука нельзя достоверно исправить без названий проблемных каналов или данных их аудиопотоков: причиной может быть неподдерживаемый устройством кодек или некорректная дорожка в потоке.

Полная сборка APK не выполнена: Gradle Wrapper не смог загрузить Gradle 8.6 из-за недоступности `services.gradle.org` в среде. Изменения исходников внесены, но компиляция и проверка на устройстве не подтверждены.

## Версия 2.76.1 — курсор категорий и fullscreen-панель

1. **Курсор категорий виден**: отдельное состояние `focusedCategory`. На чипах категорий показывается белая рамка и префикс «▶» у элемента под курсором пульта (фокус), отдельно от выбранной «✓».
2. **Раздел «КАТЕГОРИИ» над «КАНАЛЫ»**: заголовки контрастнее; список каналов явно подписан под выбранной категорией.
3. **Fullscreen больше не закрывается при «влево»**:
   - тап по видео обрабатывается через `pointerInput`/`detectTapGestures` (только касание, не DPAD);
   - `PlayerView` не забирает фокус;
   - боковая панель перехватывает тапы и не сбрасывает `isFullscreen`;
   - LEFT открывает каналы → категории, RIGHT только закрывает панель, BACK по-прежнему: сначала панель, потом выход из fullscreen.
4. Курсор в боковой панели (каналы/категории) усилен: яркая заливка, белая рамка 3dp, маркеры ▶ / ●.
5. User-Agent синхронизирован с 2.76; versionCode 94.


## Версия 2.76.2 — исправления по результатам code review

Критичное:
1. **Краш при одинаковых каналах.** В полноэкранном списке ключ строки `имя|url` мог повторяться → `Key was already used`. Теперь ключ включает индекс, а парсер M3U не добавляет полные дубликаты (имя + ссылка).
2. **Автоповтор в режиме архива.** Раньше URL пересчитывался с новым временем и не совпадал с исходным — переподключение молча не происходило. Теперь используется URL, который реально играет.
3. **Счётчик повторов** сбрасывается после 30 секунд стабильного воспроизведения (а не только при смене канала) — длинные просмотры одного канала больше не «исчерпывают» автоповтор.
4. **Ручной повтор.** Во всех режимах (телефон, ТВ, fullscreen) при ошибке есть кнопка «↻ Повторить»; также помогает тап по текущему каналу и OK на пульте в fullscreen. Ошибка теперь видна и в fullscreen.

Средней важности:
5. `hasCatchup`: типы `default` / `append` без `catchup-source` больше не показывают архив (раньше играл прямой эфир). Работают: шаблон `catchup-source` или типы shift / flussonic.
6. Flussonic-резерв: `timeshift_abs-<from>.m3u8` (было `timeshift_abs-<from>-<dur>`); база URL корректно обрабатывает `mono` / `master` / `video`. **Не проверено на реальном сервере.**
7. Ориентация: телефон определяется по `smallestScreenWidthDp` (<600). Планшеты вращаются свободно; fullscreen на телефоне — `sensorLandscape` (можно перевернуть на 180°); при выходе из fullscreen больше не мелькает ТВ-раскладка.
8. Кнопка Пауза/Пуск в телефонном интерфейсе теперь реагирует на состояние плеера.
9. Хранилище плейлистов: ошибки пишутся в Logcat (`ArturTV.Store`), перед заменой файла сохраняется `.bak`, при повреждении основного файла загрузка идёт из `.bak`, испорченный файл копируется в `.corrupt`; один битый плейлист не убивает остальные.
10. `configChanges` дополнены (`smallestScreenSize|screenLayout|uiMode|locale|layoutDirection|density|fontScale`) — смена темы/языка/размера окна не пересоздаёт Activity и не сбрасывает плеер.

Мелочи: курсор категорий (`▶`) больше не «залипает» после клика; нумерация в списке ТВ без O(n²); убрано бессмысленное присваивание `resizeMode` в factory; `setHandleAudioBecomingNoisy(true)` (пауза при отключении наушников); `gradlew` с флагом исполняемого; User-Agent 2.76.2; versionCode 95.

Не менялось: обработка клавиш пульта (на ТВ уже работает), `ndk.abiFilters` (нативных библиотек нет — безвредно).

Проверки: баланс скобок во всех .kt файлах; полная компиляция и сборка APK в этой среде невозможны (нет доступа к Gradle/Maven) — собирается через GitHub Actions (`build_apk.yml`).
